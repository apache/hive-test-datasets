# Test datasets for Apache Hive

Test datasets are stored and maintained under [nightlies.apache.org](https://nightlies.apache.org/hive/datasets/).

This repository *is not used at the moment*. 
Historically it was meant to hold datasets under the release assets but this approach raised legal concerns and was abandoned.
For more context see [LEGAL-738](https://issues.apache.org/jira/browse/LEGAL-738) and the discussion in the [dev list](https://lists.apache.org/thread.html/24j774wyz51sc83zr6b6o0mjv7ym01rq).

The repository may be permanently removed in the near future.
